Desafio de Projeto - Website HTML

A ideia deste Desafio de Projeto é elaborar um website, utilizando uma estrutura bem básica, utilizando tags aprendidas durante as aulas práticas.

Aluno: Warley Santos

Sobre

Sobre Este Projeto

Este projeto foi desenvolvido com o intuito de aplicar conceitos práticos de marcação HTML. O aprendizado de HTML é o passo fundamental para quem deseja construir páginas e aplicações para a Web.

Nesta página, demonstramos o uso de textos marcados/destacados, palavras em itálico, termos sublinhados e também partes em tamanho reduzido (small).

Também podemos representar expressões científicas ou matemáticas, como a fórmula da água (H2O, usando a tag <sub> para subscrito) ou números elevados a uma potência, como 102 = 100 (usando a tag <sup> para sobrescrito).

"A prática constante é a chave para dominar as tecnologias de desenvolvimento web."

Etapas do Desafio (Lista Ordenada)

  1. Estudar as tags básicas apresentadas em aula.
  2. Pesquisar novas tags complementares na documentação.
  3. Estruturar e publicar o website final.

Lista de Recursos Utilizados (Lista Não Ordenada)

  • Tags das aulas: <h1> a <h6>, <p>, <mark>, <small>, <i>, <u>, <strong>, <ol>, <ul>, <li>, <a>, <hr>, <sub>, <sup>, <blockquote>.
  • Novas tags pesquisadas: <abbr>, <del>, <font>.

Demonstração das Novas Tags Pesquisadas

1. Tag <abbr>: Utilizada para definir abreviações/siglas. Ao passar o mouse sobre WWW, a explicação é exibida.

2. Tag <del>: Utilizada para representar texto tachado ou removido, como um valor antigo de R$ 100,00 por R$ 50,00.

3. Tag <font>: Uma tag legada/histórica que era usada para alterar a fonte, tamanho e cor do texto. Exemplo: Texto formatado com a tag font.
